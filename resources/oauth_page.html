CommandCode 浏览器授权

支持 GOAT / Pro / Max，不支持 Go。无需提前手动创建 API key。

  1. 打开官方授权页，登录个人账户并点击“授权”。
  2. 官方自动传递失败后进入备用页，复制生成的 API key。不是复制地址栏中的网址。
  3. 将 key 粘贴到下面并验证，等待 CPA 确认保存。

这是“浏览器授权、复制凭据完成”，不是自动回调。授权仍使用 API key，不提供自动续期。只在已验证的 Chrome 默认设置下使用；不要解除浏览器对端口 6000 的限制。
